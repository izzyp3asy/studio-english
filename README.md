# Studio English

목적별 학습 폴더에서 오늘의 주제를 고르고, 짧은 영어 루틴과 표현 복습을 이어가는 반응형 학습 웹앱입니다.

## 주요 기능

- 기초 영어, 일상 회화, 업무·전문 영어 학습 경로
- 폴더 안에서 세부 분야를 선택하는 학습 흐름
- 매일 또는 직접 고른 요일에 맞춘 주간 루틴
- 날짜별 학습 기록, 복습함, 표현장
- Markdown·JSON 내보내기와 JSON 복원

업무 예시는 특정 직종에 고정되지 않습니다. 설정에서 분야를 고르거나 비워 두고 일반 업무 상황으로 학습할 수 있습니다. 앱 안에서 기록 저장 방식과 백업 방법을 확인할 수 있습니다.

## 로컬에서 열기

최신 브라우저에서 `public/index.html`을 열면 됩니다. 빌드나 패키지 설치가 필요 없습니다.

## GitHub Pages 배포

`main` 브랜치에 반영하면 `.github/workflows/pages.yml`이 `public/`을 GitHub Pages에 배포합니다. 저장소 설정에서 Pages 배포 소스로 **GitHub Actions**를 선택하세요.
